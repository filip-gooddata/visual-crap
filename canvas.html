Every dot is a function at every zoom level. The glow blends measured scores within an 18-pixel radius, giving higher scores extra influence while retaining contributions from lower scores. Its color is a weighted visual signal, not a function or region CRAP score. Grey marks estimated or unknown coverage where no measured node contributes. TypeScript resolves direct calls, constructors, JSX renders and function references where symbols can be matched. Graphify contributes separately labeled inferred calls. Function references do not prove invocation. Package entries and module initialization are unscored boundaries; exports are not calls. Static relationships can be missing or incorrect; missing edges do not imply dead code. Spring layout and directory proximity are visual aids, not evidence of runtime behavior.
